Email signatures

  1. Press Copy signature.
  2. Gmail: Settings, See all settings, Signature, Create new, paste.
  3. Outlook: Settings, Mail, Compose and reply (or Signatures), New signature, paste.
  4. Apple Mail: Settings, Signatures, add one, untick "Always match my default message font", paste.
