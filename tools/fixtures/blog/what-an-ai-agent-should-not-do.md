An agent is good at the four hundredth invoice. It is not good at deciding whether the invoice should exist.

## Where a person approves

1. Before money leaves the business.
2. Before anything is sent to a client for the first time.
3. When the agent is unsure, which it says in words rather than guessing.

## What it should never do

> An agent does not get bored on the four hundredth invoice, which is the entire point.

It should never be presented as a person. It is software, and it is called it.
